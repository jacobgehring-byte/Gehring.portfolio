Blue Robotics ESC 500 Thermal Behavior Testing

What

  • Designed and conducted an experiment to quantify heat generation from an upgraded thruster system inside a sealed pressure vessel

How

  • Prototyped a test setup with existing power system and thruster assembly along with an Arduino and custom temperature monitoring system
  • Developed Arduino IDE and Python scripts with the help of AI to control throttle and log temperature, voltage, and timestamps in a CSV file
  • Conducted multiple underwater tests with upgraded propulsion system and analyzed ESC temperature data to characterize transient and steady-state thermal behavior

Results

  • Determined an average thermal time constant of τ = 4:21 and steady-state ESC 500 temperature of 321.7 K, providing data for an upcoming journal publication
  • Demonstrated that the upgraded thruster system could operate safely within the sealed pressure vessel based on measured thermal performance

Wibotic Charging System Troubleshooting

What

  • Troubleshot and diagnosed failures in a Wibotic inductive charging system (OC-210 and TR-110)

How

  • Analyzed PCB components with a multimeter and oscilloscope, identifying a defective capacitor and modifying capacitance values to tune inductive charging frequency
  • Identified the onboard ceramic chip antenna through PCB markings and patent research, then replaced it with a larger antenna to attempt to restore radio communication
  • Diagnosed system behavior through the Wibotic GUI, packet sniffing, and serial communication.

  • Used the failure analysis to demonstrate the need to investigate alternative charging solutions
